### US001 — User Registration
**Feature:** User Registration
**Story:** As a system user, I want to register in the Supply Chain Inventory & Distribution Management System so that I can access authorized system modules.

**Acceptance Criteria:**
- User should be able to register by entering Username, Email, Password, and Role
- All fields should be mandatory and proper validation message should be displayed
- Username should be unique and system should not allow duplicate username
- Email should be validated in proper email format and duplicate email should be rejected
- Password should have minimum 8 characters with at least one uppercase letter, number and special character
- Role should be selected from predefined roles such as Administrator, Warehouse Manager, Sales Executive, Distribution Manager, Management
- System should validate all details before creating the user account
- Password should be stored securely in encrypted/hashed format
- On successful registration, user account should be created with active status
- Registration confirmation message should be displayed after successful registration

### US002 — Secure Login
**Feature:** Secure Login
**Story:** As a system user, I want to log in to the application so that I can access authorized functionalities.

**Acceptance Criteria:**
- User should be able to enter Username and Password
- Username and Password fields should be mandatory
- System should validate credentials against registered user records
- Invalid credentials should display a proper error message without revealing which field was incorrect
- Inactive or blocked users should not be allowed to log in
- Successful login should authenticate the user and redirect to the dashboard
- JWT token should be generated after successful authentication
- JWT token should be used for accessing secured APIs
- Token expiry/session timeout should be handled as per security policy

### US003 — Role Based Access
**Feature:** Role Based Access
**Story:** As an Administrator, I want to create and manage user accounts so that only authorized personnel have system access.

**Acceptance Criteria:**
- Administrator should be able to create, edit, activate and deactivate users
- User details such as Username, Email, Role and Status should be maintained
- Role assignment should be mandatory while creating or updating a user
- System should allow only predefined roles such as Administrator, Warehouse Manager, Sales Executive, Distribution Manager, Management
- Administrator should not be able to save user details without assigning a role
- User status should be maintained as Active or Inactive
- Inactive users should not be allowed to access the system
- Any changes made to user role or status should be saved successfully
- Proper success or error message should be displayed after create/edit actions
